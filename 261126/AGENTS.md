# 自作言語とVMの作業指示

- [リポジトリ共通指示](../AGENTS.md)に従う。変更は `261126/` とルート `README.md` の本企画の項目に収める。
- `feat/language-vm` にコミットしてpushし、`main` を取り込み先とするDraft PRで確認する。`main` への直接pushとマージは行わない。
- 実装とテストは[言語仕様](docs/language_spec.md)を基準にする。仕様を変えるときは変更理由を[作業ログ](work_log.md)に記録し、例と期待値も更新する。
- 期待値は仕様から導く。AST評価器とVMの出力を期待値の作成に使わない。二つの処理系を比較するときは、標準出力、診断コード、診断段階、位置、終了コードを確認する。実行ステップ上限の扱いは仕様に従う。
- 実装はPython 3.12の標準ライブラリで進める。入力されたソースは自作の処理系で実行する。
- 日本語文書の変更には `yomiyasu` を使う。検査結果と、仕様やテストに基づく技術的な確認を[作業ログ](work_log.md)に記録する。 [日本語技術文書の書き方](../docs/engineering/japanese-writing.md)
