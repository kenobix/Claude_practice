## 知見の追加と更新

プロジェクトを完了したときは、同種の作業で使える知見が得られたか確認します。該当する節があれば、実測や仕様に基づいて更新します。別の条件に当てはまる知見なら、対応する資料に短い節を追加します。具体的な経緯は各プロジェクトの作業ログや受入記録に残し、ここからリンクします。

適用条件、問題と原因、有効だった対策、次回の確認方法、適用限界を書きます。元プロジェクトの設計・実装・テスト、PRやコミットのうち、判断を再確認できる箇所にリンクします。失敗、未実施、推測、実測を区別し、生成AIの報告は差分や記録で裏づけます。検証で既存の知見が覆った場合は、新しい根拠を示して元の節を更新します。索引には、新しい作業の入口が必要になったときに行を追加します。
