# archive/ について

このフォルダにあるのは、簿記2級カードセットの図解画像をAI画像生成(Gemini/GPT)で
作るために使っていたプロンプト集の記録です。

## なぜアーカイブしたか

QAの結果、数値の矛盾・無関係なテーマの混入・文字化けといった構造的な欠陥が
繰り返し見つかり、これはプロンプトの工夫では解決しない拡散モデルの限界だと
判断しました。そのため「数値・矢印関係が重要な構造図」は AI画像生成をやめ、
`js/diagrams/` 配下に `createElementNS` で直接書くインラインSVGに切り替えています。
経緯・移行状況は [../svg-diagram-migration.md](../svg-diagram-migration.md) を参照。

## 今も使う理由

各ファイルの「何を描くべきか」という内容仕様(トピック・必須要素・想定される
数値関係)の記述は、SVGを書く際の仕様書としてそのまま使えるため、削除せず
保管しています。**新しい画像生成には使わないでください。**

- `image-generation-prompts-archive.md` — 最初に配線した15枚の元プロンプト
- `image-generation-prompts-additional.md` — 追加14枚のプロンプト(生成後、13枚に品質問題が見つかった)
- `image-regeneration-prompts.md` — 上記のうち品質問題が出た20枚向けに、混入防止・数値検算の注意書きを追加した修正版プロンプト
