# 画像の再生成プロンプト集(品質問題があった20枚)

Gemini 3.6 Flashで生成した簿記2級用の画像29枚(既存15枚+追加14枚)をClaude(ユーザー側)と本セッションの両方で目視確認した結果、20枚に実害のある問題(無関係なテーマの図・数値がそのまま混入している/計算が矛盾している/プロンプトの指示文がそのまま描画されている)が見つかった。詳細な内訳・重大度は会話ログを参照。

**わかった主な原因**: 多くの画像で、以下5種類の「他テーマのパネル」が本来のテーマとは無関係にそのまま(数値まで完全一致で)混入していた。
- 連結会計の相殺消去・非支配株主持分パネル(「親会社(A) ¥5,000 → 相殺消去 → 子会社資本/非支配株主持分」)
- 圧縮記帳の償却曲線パネル(「¥5,000 → 圧縮損計上後の帳簿価額 → 切替ポイント ¥2,000」)
- 仕損・減損の度外視法パネル(「期首仕掛品¥5,000 ¥1,000 > 正常品原価¥5,000」)
- 部門別配賦のA/B/C部門フロー(「補助部門A/B/C → 製造部門1/2/3/4」)
- 製造間接費の配賦差異バーグラフ(「予定配賦額¥5,000 / 実際発生額¥5,500」)

このため、以下の20プロンプトすべてに、末尾へ**「厳守事項」ブロック**(上記5種のパネルの流用禁止・数値の検算・指示文の描画禁止)を追加した。それ以外の内容(テーマ・構成)は据え置き。まずこの安全策入りプロンプトで再生成し、それでも同じ問題が再発する場合は生成AI・モデルを変えることも検討してほしい。

生成後は必ず一度目を通し、特に「厳守事項」で挙げた5パネルが紛れ込んでいないか、数値が整合しているかを確認すること。
