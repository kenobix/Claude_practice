# 忘却曲線フラッシュカードアプリ

エビングハウスの忘却曲線を使った間隔反復（Spaced Repetition）学習アプリ。GitHub Pagesで動作する静的サイト（外部API・ビルド不要）。

**公開URL:** https://kenobix.github.io/Claude_practice/260905/

## 何を作ったか

- カードの表面（問い）・裏面（答え）を登録し、復習セッションで自己評価しながら覚える単純なフラッシュカードアプリ
- ダッシュボードのヒーロー要素として、登録カードそれぞれの忘却曲線（薄い線）と全体の平均忘却曲線（太いアクセント線）を1枚のSVGチャートに重ねて表示。「今」を境に、過去の実績と将来の予測がひと続きの曲線として見える
- 復習のたびに「もう一度 / 難しい / 普通 / 簡単」の4段階で自己評価し、評価に応じて次の復習日を自動計算
- すべて `localStorage` に保存。サーバー・APIキーなし

## 忘却曲線と間隔反復のロジック

保持率 `R` を、経過日数 `t`・カードごとの「安定度」`S`（日）を使って次の式で近似している。

```
R(t) = 0.9 ^ (t / S)
```

`S` は「保持率が90%まで落ちるのにかかる日数」として定義しており、`t = S` の時点で必ず `R = 0.9` になる。エビングハウスの指数関数的な減衰の形をそのまま使いつつ、`S` を直接「次の復習までの間隔（日数）」として扱えるようにした簡易版（Ankiの2.0以前のアルゴリズムに近い考え方）。

復習時の自己評価によって `S` を更新する（簡易SM-2方式）。

| 評価 | 新しい安定度 |
|---|---|
| もう一度 | `S × 0.3`（最低1日） |
| 難しい | `S × 1.2` |
| 普通 | `S × 2.5` |
| 簡単 | `S × 3.5` |

新規カードの初期安定度は1日。次回復習日は `最終復習日時 + 新しい安定度(日)` で算出する。「もう一度」を選んだカードは、その場の復習セッション内でも数枚後にもう一度出題される。

より精密なFSRS（Free Spaced Repetition Scheduler）のような、実際の保持率や難易度パラメータまで加味したアルゴリズムではないが、「忘却曲線を可視化しながら間隔反復で学ぶ」という体験を成立させるには十分な近似として採用した。

## 設計上の判断

- **UIデザイン**: `anthropics/skills@frontend-design`（GitHub上のAgent Skills、855.9K install・Anthropic公式）をプロジェクトスコープで導入し、その原則に沿って設計した。
  - クリーム背景+テラコッタ配色や黒背景+ネオン配色など「AI生成っぽい」定番配色を避け、「紙の上のインク」という主題（記憶の強弱＝インクの濃淡）に根ざした配色にした（寒色寄りのペーパーグレー `#EEF0EA` + 琥珀色のアクセント `#C6862B` 1色のみ）
  - ダッシュボードのヒーローは「大きい数字+グラデーション」の定番ではなく、忘却曲線グラフそのものにした
  - カード一覧のカード文字色は、そのカードの現在の保持率に応じてインクの濃さ（強い記憶=濃いインク・弱い記憶=薄いインク）で表現。これは装飾ではなく情報を担う視覚要素として設計した
  - モーションはカード反転の1箇所と、ダッシュボード表示時の平均曲線の描画アニメーションのみに絞り、`prefers-reduced-motion` を尊重する
- **チャートの設計**: dataviz観点のガイドライン（1系列を強調し他を控えめにする「emphasis」パターン、ホバー時のクロスヘア+ツールチップ、表ビューという代替手段の提供、軸ラベルは`tabular-nums`、系列の色を文字に使わない等）に沿って自作SVGで実装。外部チャートライブラリは使っていない
- **データ構造**: 3ファイル構成（`index.html` / `style.css` / `app.js`）。フレームワーク・ビルドステップなし。既存の `260521`・`260630` の単一HTML完結パターンより機能量が多いため、素直にファイルを分割した
- 初回アクセス時はデモ用のサンプルカードが4枚自動で入る（`localStorage`が空の場合のみ）。ダッシュボードの曲線がすぐに意味を持つようにするための仕込みで、いつでも削除・編集できる

## 確認方法

```
cd 260905
python3 -m http.server 8905
# ブラウザで http://localhost:8905/ を開く
```

- カード追加→一覧に反映されること、次回復習日・保持率が表示されること
- 復習セッションでカードをクリック/Enter/Spaceキーで反転し、4段階評価で次のカードに進むこと。「もう一度」を選んだカードが同じセッション内で再度出題されること
- ダッシュボードのグラフがカードの状態を反映し、ホバーでクロスヘア＋ツールチップが出ること。「表で見る」から表ビューに切り替えられること
- ページをリロードしても`localStorage`からカード・復習履歴が復元されること
- モバイル幅（375px程度）でもレイアウトが崩れないこと
