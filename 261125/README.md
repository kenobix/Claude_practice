# リアルタイム共同編集アプリ

少人数の勉強会で使うテキスト共同編集アプリです。一時的な切断中も編集を続け、再接続後に変更を合流させます。端末内保存とサーバー保存の状態を表示し、文書の権限変更や削除後の同期も扱います。 [2026年10月14日の計画](../261014/plan_collaborative_editor.md)

Phase 0では3つの `Y.Doc` に更新を逆順や重複で配送し、一部の更新を保留してから届けました。結果をもとにMVPの仕様とフェーズごとの受入条件を定めました。アプリの実装はPhase 1のオンライン共同編集から始めます。 [実験と環境の記録](work_log.md)

## Phase 0の実験を再現する

Node.js 22.22.2とnpm 10.9.7で確認しました。依存の取得にはnpmレジストリへの接続が必要です。

```bash
cd 261125/experiments
npm ci --ignore-scripts
npm test
```

各端末が受け取った更新の順番、保留の前後の本文、Yjsバイナリのバイト数を出力します。
